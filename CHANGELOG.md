# Changelog

## 0.3.2

- Release files are now built by GitHub Actions with a signed build provenance attestation.
- Finished tasks use a plain strikethrough, which every supported Obsidian version renders the same way.

## 0.3.1

- On phones and tablets, a row you tapped no longer stays highlighted. Hover highlights apply only on devices with a pointer.

## 0.3.0

- First public release. Countdown view for Bases and a Next deadlines sidebar for TaskNotes due dates, with steps left, the pace a day, when each step must start, and who you are waiting on.
- Time-gone bar, a short "finished early" moment, a share image, the next deadline in the status bar, and a `tasknotes-countdown` block for daily notes.
